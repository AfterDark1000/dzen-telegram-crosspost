# VK: ежедневные срезы статистики ХПИИ

Автоматический сценарий: .github/workflows/vk-stats.yml.

**Это отдельный сборщик.** Он не публикует сообщения и не меняет
состояние кросспостинга, редакционных очередей или списки отправленных статей.

## Время и хранение

Каждый день около **00:23 по Усть-Катаву (UTC+5)** GitHub Actions
пытается снять текущие значения и сохранить JSON в папку stats/vk/
(один файл на день в формате YYYY-MM-DD.json).
GitHub Actions запускает cron по возможности, поэтому возможны
задержки и пропуски. При обновлении самого сборщика он также запускается
один раз после изменения main; есть ручной запуск через Actions.

Значения просмотров записей — накопительные, а не просмотры за день.
Для недельного отчёта нужно сравнивать счётчики одной и той же записи
между двумя срезами. Уникальный охват из просмотров вычислять нельзя.

## Источник данных и ограничения

- VK_ACCESS_TOKEN — уже используемый токен сообщества для публикации.
  Им в первую очередь пробуем прочитать количество участников.
- VK_READ_ACCESS_TOKEN (необязательный GitHub Actions Secret) —
  отдельный сервисный или иной токен с правом чтения публичной стены.
  Без него сборщик попробует существующий токен сообщества.
  При успехе сохраняются идентификаторы и счётчики до 300 недавних
  публикаций, без персональных данных подписчиков.
- VK_STATS_ACCESS_TOKEN (необязательный GitHub Actions Secret) —
  токен администратора, если VK действительно позволяет ему вызывать
  stats.get. Это дополнительный запрос за последние 14 дней.
- Более подробная статистика stats.getPostReach для маленьких сообществ
  может быть недоступна даже с правильным токеном.

Токены не хранятся в JSON и не выводятся в лог. Они доступны только
основному запуску, а не PR-тестам.

В срезе есть отдельные статусы ok и unavailable с кодом ошибки VK.
**unavailable — не ноль.** Если VK запретил чтение стены, сумма
просмотров неизвестна, а не равна нулю. Если отказывает всё API,
сборщик завершает работу с ошибкой и пустой срез не создаётся.

Для проверки запуска: Actions → VK daily audience snapshot (READ ONLY).
По понедельникам достаточно попросить «сравни VK за неделю»,
чтобы считать динамику из накопленных файлов. Если API не даёт
доступ к подробным охватам, прежние XLS остаются источником этих данных.
