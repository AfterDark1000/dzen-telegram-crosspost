# Buffer + X для «Хроник Пикирующего ИИ»

30 октября 2026: отдельный X-аккаунт [@iipike_ai](https://x.com/iipike_ai) привязан к Buffer. Ключ **BUFFER_API_KEY** добавлен пользователем в GitHub Actions secrets.

Первый этап: только проверка подключения, workflow `buffer-x-check.yml`. Команда `python3 buffer_x_check.py` читает Buffer GraphQL `https://api.buffer.com`: список организаций и подключённых X-каналов. **Никакие посты не создаются и не ставятся в очередь**, при ошибке выводится диагностическое сообщение без ключа.

Следующий этап — только после успешной проверки: безопасный отдельный публикационный модуль и журнал отправленных статей с проверкой дублей. На бесплатном тарифе Buffer максимум десять запланированных постов на канал одновременно. Существующие Telegram, VK, Threads не изменять. Instagram остаётся на паузе. Запрещено автоматически публиковать старый архив Дзена.

Документация Buffer: https://developers.buffer.com/guides/your-first-post.html
