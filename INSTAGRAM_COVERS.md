# Вертикальные обложки для Instagram ХПИИ

## Уже подключено

- Канал-приёмник: **«ХПИИ — Обложки Instagram»** (закрытый канал, бот @iipike_post_bot — администратор).
- При очередном часовом запуске существующего процесса программа `instagram_cover_inbox.py` читает новые `channel_post` этого бота.
- Если канал ещё не известен программе, он определяется **по точному названию**. Чужие каналы игнорируются.
- Сообщение: одна фотография **1080×1350 (4:5)** или файл PNG/JPEG. Подпись — **только точный заголовок статьи из Дзена**, без ссылки, хэштегов или дополнительных строк.
- Исходный файл преобразуется в JPEG 1080×1350 без обрезки изображения. Картинка сохраняется в `instagram_covers/`, индекс и ID последнего обновления — в `instagram_cover_inbox.json`.
- После выхода статьи в Дзене `instagram_crosspost.py` сохраняет её в `instagram_pending_articles.json`. Когда есть точное совпадение нормализованных заголовков, публикуется **только вертикальная обложка**, а не пейзажная обложка Дзена.
- Если совпадение не найдено, статья **ждёт**, другие соцсети работают в прежнем режиме.
- Уже опубликованные Instagram статьи остаются в `seen_instagram_articles.json` и не отправляются повторно.

## Когда проверять

На первом тесте положить обложку будущей статьи в Telegram-канал, дождаться очередного запуска:
https://github.com/AfterDark1000/dzen-telegram-crosspost/actions/workflows/crosspost.yml

В журнале шага `Collect vertical Instagram covers from Telegram channel` ожидается `Instagram cover inbox channel confirmed` и `Saved vertical cover for: ...`. Должен появиться соответствующий JPEG в `instagram_covers/`. **До появления публичной новости картинка в Instagram не публикуется.**

### Технические условия

- Без нового API-ключа: уже существующий `TELEGRAM_BOT_TOKEN`.
- Бот **должен быть администратором** канала и получать события `channel_post`. Если бот обслуживается чужим webhook или другим потребителем `getUpdates`, синхронизация может конфликтовать.
- Канал может быть закрытым, но его **готовые картинки публикуются в открытом репозитории** и доступны любому по прямой ссылке; хранить здесь личные фотографии нельзя.
- Репозиторий не содержит токенов. Публичный JPEG GitHub необходим, поскольку Instagram API загружает изображение по HTTPS.
- Если надпись в Telegram отличается от заголовка Дзена, совпадение не сработает: отправить фото повторно с исправленной подписью.
- Для защиты от случайной публикации некорректного файла горизонтальные и неопознанные картинки отклоняются, без автоматической обрезки.
- При первом сопоставлении заголовков используются только уже опубликованные статьи Дзена, которые удалось обнаружить. Автоматическая публикация не включается для запланированных/отложенных статей до их появления в публичной ленте.
